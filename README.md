# Análise da Depressão em Estudantes

## Sobre o Projeto

Este projeto tem como objetivo analisar dados relacionados com a depressão em estudantes, através da criação de visualizações no Tableau. A análise procura explorar possíveis relações entre indicadores de saúde mental, pressão académica, hábitos de vida e outros fatores associados ao contexto estudantil.

## Objetivos

- Explorar as principais características do conjunto de dados.
- Identificar padrões relacionados com a depressão em estudantes.
- Analisar possíveis relações entre fatores académicos, hábitos de vida e indicadores de saúde mental.
- Desenvolver visualizações que facilitem a interpretação dos dados.
- Comunicar os resultados através de gráficos e dashboards.

## Ferramentas Utilizadas

- **Tableau:** análise visual dos dados e criação de gráficos e dashboards.
- **CSV:** formato do conjunto de dados utilizado na análise.

## Conjunto de Dados

O projeto utiliza um conjunto de dados sobre a depressão em estudantes, que inclui informação sobre diferentes características demográficas, académicas e hábitos de vida.

Os dados são explorados com o objetivo de identificar padrões e possíveis associações entre as variáveis disponíveis.

## Questões de Análise

- Que padrões podem ser identificados nos dados relativos à depressão em estudantes?
- Que relação existe entre a pressão académica e os indicadores de depressão?
- Como se relacionam os hábitos de vida com os indicadores de saúde mental?
- Que diferenças podem ser observadas entre os diferentes grupos de estudantes?
